## 1. 가장 먼저 수정: "10 audited areas"와 실제 목록의 표현

현재:

> "ten audited areas (the nine originally requested areas plus Simulation)" 

라고 했고, 바로 뒤에서:

> API Boundary is explicitly not treated as a domain

이라고 했습니다.

그런데 원래 9개에 **API가 포함되어 있었고**, 지금은 API를 domain에서 제외했기 때문에 문장 자체가 약간 혼란스럽습니다.

현재 실제 core domains는:

1. Persona
2. Scenario
3. Session
4. Evaluation
5. Emotion
6. Voice
7. Avatar
8. Auth
9. Simulation

즉 **9개 core domains**입니다.

API Boundary는 별도 boundary layer입니다.

따라서 다음처럼 바꾸는 것이 정확합니다.

> **The document clearly separates the nine core domains from the cross-cutting API Boundary layer.**

그리고:

> `nine originally requested areas plus Simulation`

도 수정해야 합니다.

왜냐하면 원래 요청의 9개에는 API가 포함되어 있었기 때문입니다.

### 추천 문구

```text
The document clearly separates the nine core domains
(Persona, Scenario, Session, Evaluation, Emotion, Voice, Avatar,
Auth, and Simulation) from the cross-cutting API Boundary layer.
API Boundary is explicitly not treated as a domain.
```

그리고 Step 1도:

```text
Audit the nine core domains, while treating API as a cross-cutting
boundary layer rather than a domain.
```

으로 바꾸는 게 정확합니다.

**이건 숫자보다 개념적 정확성의 문제입니다.**
