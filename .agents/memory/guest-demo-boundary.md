---
name: 계정 없는 게스트 체험
description: 공개 시나리오 체험 세션의 데이터 및 권한 경계
---

게스트 체험은 회원으로 로그인하는 방식이 아니라 방문자별 임시 세션이다. 공개·체험으로 지정된 무료 시나리오만 대상으로 하고, 게스트 대화는 회원 훈련 기록이나 회원 분석에 포함하지 않는다.

**Why:** 공용 게스트 계정의 누락은 모두의 체험을 막고, 공용 계정이 있어도 다른 방문자의 완료 상태와 기록이 공유될 수 있다. 계정 없이 체험한다는 요청이 회원 권한이나 구독 콘텐츠 접근을 허용하지는 않는다.

**How to apply:** 로그인 버튼 수정 시 실제 첫 대화와 새로고침을 확인하고, 독립 브라우저 두 개에서 완료 상태 및 대화가 공유되지 않는지 확인한다. 회원 인증과 다른 체험 쿠키를 유지하고 공개 여부와 유료 콘텐츠 제외 조건을 서버에서 확인한다.
