---
name: 자동 충돌 병합 검증
description: 자동 병합 결과에서 충돌 표시 밖의 선언 중복까지 확인해야 하는 이유
---

충돌 표시 제거만으로 자동 병합 결과를 정상으로 간주하지 않는다.

**Why:** 자동 병합의 충돌 표시는 모든 의미적·구문적 결함의 목록이 아니다. 표시 밖의 선언 중복도 검사해야 기존 기능과 새 동작을 안전하게 보존할 수 있다.

**How to apply:** 병합을 계속하기 전에 타입 검사와 영향을 받은 테스트를 실행한다. 기존 화면 변경과 새 동작을 함께 보존하고, 한쪽 파일 전체 선택으로 다른 작업을 지우지 않는다.
