---
name: 대화 언어 고정 정책
description: 화면 언어와 실행 언어의 경계 및 과거 실행의 언어 추정 원칙
---

대화 시작 때 선택한 언어는 텍스트·음성·아바타·피드백에서 동일하게 유지한다. 프로필이나 화면 언어 변경은 새 대화에 적용하며, 실행에 묶인 언어가 최우선이다.

**Why:** 모드마다 최신 프로필 또는 실행 스냅샷을 다르게 참조하면 같은 대화 안에서 생성·전사·평가 언어가 갈라진다. 사용자 요청에 따라 통합 개선의 기준으로 채택했다.

**How to apply:** 브라우저 인식도 서버가 알려준 대화 언어를 기다린다. 외부 API가 명시한 대화 언어는 웹 사용자 설정으로 덮지 않는다. 제공자 전사 설정 변환은 AvatarRouter에 유지한다.

언어가 저장되지 않았던 과거 실행은 원래 언어를 복구했다고 주장하지 않는다. 실행 스냅샷에 언어가 있으면 사용하고, 없으면 첫 접근 시 소유자의 현재 언어를 조건부 저장해 이후 변경을 막는다.

**Why:** 과거 언어의 신뢰할 기록이 없으면 현재 프로필로 대화 시작 당시 언어를 추정할 수 없다.

**How to apply:** 과거 데이터 일괄 소급 변경이나 전사 번역을 피하고, 명시적 언어 변경 기능을 만들 경우 기존 대화와 새 대화의 경계를 먼저 정한다.
