---
name: 라이브 음성 성별 진단
description: AvatarRouter 음성 분류와 실제 대화 음성 적용을 확인하는 기준
---

페르소나 성별, 음성 목록 성별 필터, 실제 선택한 제공자 음성을 구분한다. 분류는 AvatarRouter가 맡으며, 미분류 음성의 성별을 이름으로 추정하거나 다른 제공자의 음성을 대신 연결하지 않는다.

**Why:** Tavus 카탈로그는 제공자 성별 메타데이터가 없는 음성을 반환할 수 있다. 이 경우 분류 필터가 비어도 음성 카탈로그가 비었거나 제공자가 남성 음성을 제공하지 않는다는 뜻은 아니다. 적용된 음성 지정이 없으면 AvatarRouter는 제공자 기본 음성을 사용하며, 실행 시작 기록만으로 그 음성 모델을 식별할 수 없다.

**How to apply:** 권한 있는 읽기 요청으로 현재 제공자 카탈로그의 `X-Voice-Catalog-Next-Offset`을 끝까지 따라가며 분류·사용 가능 여부를 집계한다. 첫 페이지가 요청한 크기보다 짧아도 뒷페이지가 있을 수 있다. 사용자 설정과 실행에 고정된 음성 지정을 따로 확인하고, 변경이 필요하면 실제로 확인한 음성을 라우터 운영자 분류를 통해 등록한다. 유료 통화 재생 확인은 별도 승인 후 진행한다.
