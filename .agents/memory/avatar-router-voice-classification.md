---
name: 라이브 음성 성별 진단
description: AvatarRouter 음성 분류와 실제 대화 음성 적용을 확인하는 기준
---

페르소나 성별, 음성 목록 성별 필터, 실제 선택한 제공자 음성을 구분한다. 분류는 AvatarRouter가 맡으며, 미분류 음성의 성별을 이름으로 추정하거나 다른 제공자의 음성을 대신 연결하지 않는다.

**Why:** Tavus 카탈로그는 제공자 성별 메타데이터가 없는 음성을 반환할 수 있다. 이 경우 분류 필터가 비어도 음성 카탈로그가 비었거나 제공자가 남성 음성을 제공하지 않는다는 뜻은 아니다. 적용된 음성 지정이 없으면 AvatarRouter는 제공자 기본 음성을 사용하며, 실행 시작 기록만으로 그 음성 모델을 식별할 수 없다.

**How to apply:** 권한 있는 읽기 요청으로 현재 제공자 카탈로그의 `X-Voice-Catalog-Next-Offset`을 끝까지 따라가며 분류·사용 가능 여부를 집계한다. 첫 페이지가 요청한 크기보다 짧아도 뒷페이지가 있을 수 있다. 사용자 설정과 실행에 고정된 음성 지정을 따로 확인하고, 변경이 필요하면 실제로 확인한 음성을 라우터 운영자 분류를 통해 등록한다. 유료 통화 재생 확인은 별도 승인 후 진행한다.

기존 렌더링 연결 테스트는 앱이 생성한 PCM을 보내므로 공급자 음성 모델 비교에는 사용하지 않는다. 실제 공급자 음성을 비교할 때는 인증된 라우터가 `provider_voice_catalog_v1` 및 해당 네이티브 파이프라인을 광고하는지 확인한다.

**Why:** 선택 UI만 바꾸거나 외부 PCM에 공급자 음성 ID를 붙여도 실제 발화 음성은 바뀌지 않는다. 라우터의 최신 OpenAPI와 인증 기능이 오래된 제공자별 사용 가이드보다 먼저 변경될 수 있다.

**How to apply:** 비교 음성은 해당 공급자의 목록에서 고르고 새 네이티브 테스트 세션에만 보낸다. 목록 미분류 음성은 성별을 추정하지 말고, 거절된 선택을 기본 음성으로 자동 재시도하지 않는다. 기존 회원 시나리오·페르소나 설정·평가와 별개로 유지한다.

Anam 기본 아바타와 음성 카탈로그가 동작하더라도 Anam 맞춤 라이브 자산을 쓸 수 있다는 뜻은 아니다. 2026-11-23 연결 확인에서는 기본 Anam 아바타 1개와 여러 페이지의 음성이 있었지만, 인증 응답의 `customLiveProviders`에는 Tavus만 있었다.

**Why:** 라우터는 기본 아바타, 음성, 이미지에서 만든 프로젝트 자산, 해당 자산의 실제 라이브 실행을 별도 계약으로 제공한다. 프로젝트 자산 목록에 Anam 항목이 있어도 실행 가능 상태나 공급자 지원을 보장하지 않는다.

**How to apply:** 새 조회 결과와 공급자 기능을 확인해 각각 표시한다. 페이지를 이어서 읽어 선택한 음성을 확인하고 저장할 때도 같은 공급자와 프로젝트의 전체 목록에서 일치 여부를 검사한다. 지원되지 않는 맞춤 생성·연결을 Tavus로 대신 보내지 않는다.
