---
name: 콘텐츠 관리 UX/UI 통일 원칙
description: 콘텐츠 관리 편집 화면의 기준과 중복 코드 방지에 관한 사용자 지침
---

평가기준과 컬쳐맵도 시나리오·페르소나 수정 페이지를 기준으로 동일한 UX/UI 구조를 사용한다.
콘텐츠 관리 메뉴의 관리 스타일을 정리할 때 화면별로 중복 코드를 만들지 않는다.

**Why:** 사용자가 콘텐츠 관리 전반의 일관성과 코드 중복 방지를 명시적으로 요청했다.

**How to apply:** 콘텐츠 관리의 생성·수정 화면을 추가하거나 변경할 때 기존 공통 편집 틀과 컨트롤을 먼저 확장한다. 메뉴마다 별도의 편집 틀을 복사하지 않는다.
