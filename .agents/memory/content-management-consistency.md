---
name: 콘텐츠 관리 UX/UI 통일 원칙
description: 콘텐츠 관리 편집 화면의 기준과 중복 코드 방지에 관한 사용자 지침
---

평가기준과 컬쳐맵도 시나리오·페르소나 수정 페이지를 기준으로 동일한 UX/UI 구조를 사용한다.
관리자·운영자 메뉴와 적용 가능한 다른 메뉴에도 좌측 섹션 메뉴, 모바일 섹션 이동, 상단 저장·닫기, 하단 이전·다음을 확대 적용한다.
관리 화면의 스타일을 정리할 때 화면별로 중복 코드를 만들지 않는다.

**Why:** 사용자가 콘텐츠 관리에 이어 관리자·운영자와 가능한 다른 메뉴까지 공통 UX/UI를 확대하고 중복 코드를 줄이도록 명시적으로 요청했다.

**How to apply:** 관리 메뉴와 생성·수정 화면을 추가하거나 변경할 때 기존 공통 탐색·편집 틀과 컨트롤을 먼저 확장한다. 메뉴마다 별도의 틀을 복사하지 않는다. 조회 화면과 개별 저장 작업에는 실제 저장 범위를 유지한다.
