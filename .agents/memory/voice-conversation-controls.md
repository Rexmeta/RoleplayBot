---
name: 음성 대화의 선택형 컨트롤
description: 사용자가 설명한 음성 대화 화면의 옵션 노출 원칙
---

음성 대화창에서 텍스트·라이브 아바타 전환은 하단의 기존 텍스트 버튼 위치에
통합하고, 눌러야 하는 옵션처럼 눈에 확연히 띄게 표현하지 않는다.
상단 히든 바에는 중복된 라이브 아바타 옵션을 배치하지 않는다.

**Why:** 사용자는 이미 음성 대화를 선택하고 들어왔기 때문에 다른 방식이
명시적으로 드러날 필요가 없다고 설명했다.

**How to apply:** 음성 대화를 기본으로 유지하고, 방식 전환과 라이브 설정은
사용자가 원할 때 하단 선택 기능으로 열 수 있도록 한다.

라이브 아바타 대화창도 현재 음성 대화창과 동일한 UX/UI로 통합한다.

**Why:** 사용자가 화면 간 차이로 유저에게 혼란을 주고 싶지 않다고 설명하며 동일한 구성을 다시 요청했다.

**How to apply:** 헤더·하단 조작 영역·대화 내역의 공통 구성을 유지한다.
외부 제공자 동의·유료 시작·복구 절차는 보존하며, 제공자가 지원하지 않는 마이크 제어를 있는 것처럼 표시하지 않는다.
