---
name: Tavus Full Pipeline boundaries
description: 사용자가 지정한 독립 Tavus 모드와 공통 PAL 재사용 원칙
---

Tavus 라이브 아바타는 Gemini Live 음성을 중계하는 모드가 아니라 Tavus가 STT·LLM·TTS·Avatar·Lip Sync를 모두 처리하는 독립 모드로 유지한다. 기존 텍스트와 Gemini Live 모드는 보존한다.

**Why:** 사용자가 Tavus Full Pipeline을 별도 모드로 구현하도록 명시적으로 요청했다.

**How to apply:** Tavus 경로에서 Gemini Live WebSocket이나 AvatarRouter 오디오 중계를 추가하지 않는다. 기존 평가 로직은 유지하고 제공자가 확정한 전사 기록을 어댑터로 연결한다.

Tavus를 직접 연결하지 말고 이미 연결된 아바타 라우터를 통해 연결해야 한다.

**Why:** 사용자가 직접 Tavus 연결 대신 기존 아바타 라우터를 사용하라고 명시적으로 정정했다.

**How to apply:** RoleplayX에서 Tavus API 키를 요청하거나 Tavus REST API를 직접 호출하지 않는다. 기존 라우터의 서버 전용 프로젝트 키 경계를 재사용한다. PCM 렌더러와 STT·LLM·TTS 전체 파이프라인을 혼동하지 않고, 라우터의 Full Pipeline 계약이 확인되지 않으면 우회 호출 대신 지원 필요 상태를 표시한다.

페르소나별 PAL 생성 대신 고정된 공통 PAL 하나를 재사용하고, 시작할 때 페르소나 특성과 시나리오를 동적 컨텍스트로 전달한다.

**Why:** 사용자가 최초에는 공통 PAL 하나만 사용하고 불필요한 기존 스키마 변경을 피하라고 요청했다. 이후 라우터의 세션별 PAL 생성·120초 제한·확정 대화록 API 부재를 설명하고 축소 연결과 기존 요구사항 유지 중 선택을 요청했을 때도 “기존 요구사항 유지”를 선택했다.

**How to apply:** 세션별 역할 변경을 위해 공유 PAL을 수정하지 않는다. 공통 PAL의 물리적 목소리 공유와 컨텍스트에 따른 말투·행동 차이를 구분하고, 실제 역할 유지나 미디어 품질은 모의 테스트로 검증됐다고 주장하지 않는다.

공통 PAL 재사용, 시나리오 목표 시간, 확정 대화록 평가 연결은 장기 요구사항이다. 단, 사용자는 이후 “현재 구현된 상태로 우선 라이브 아바타를 실행 할 수 있도록 구현해”라고 요청하여 현재 라우터 방식으로 우선 실행하도록 범위를 변경했다.

**Why:** 기존 요구사항 유지 선택 뒤 사용자가 현재 구현된 상태로 우선 실행할 수 있게 하라고 명시적으로 지시했다.

**How to apply:** 우선 실행 단계에서는 세션별 PAL·120초 제한·확정 대화록 및 평가 미지원 상태를 명시하고 연결한다. 공통 PAL 제약을 이유로 이 우선 실행을 다시 차단하지 않는다. 직접 Tavus 호출, 임시 자막의 확정 대화록 대체, 평가 연동 완료 주장은 금지한다.

무료 사전 검사에서 생성이 차단된 경우와 유료 생성 요청의 결과가 불명확한 경우를 구분한다. 기능·페르소나 선택 자격과 일시적 실행 가능 여부도 별도로 취급한다.

**Why:** 사전 차단을 생성 결과 불명으로 취급하면 존재하지 않는 세션의 종료를 요구하고 수동 재시도를 막는다. 반대로 실제 생성 결과가 불명확한 요청을 재시도하면 중복 과금 위험이 있다. 일시적 차단 때문에 모드 진입을 막으면 진단 화면에도 접근할 수 없다.

**How to apply:** 서버가 생성 요청 미전송을 명시적으로 보장한 경우에만 무료 상태 재확인 후 수동 시작을 허용한다. 유료 생성 요청 이후의 실패와 네트워크 오류에는 이 보장을 붙이지 않는다. 실행 차단 상태에서도 자격이 있는 사용자는 사유 확인 화면에 접근할 수 있게 한다.
