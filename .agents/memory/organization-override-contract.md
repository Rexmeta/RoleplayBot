---
name: Organization override boundaries
description: 조직 실행 소속과 실제 피드백 가중치 계약을 혼동하지 않기 위한 결정
---

조직 설정은 새 실행에서만 고정하며, 과거 실행에 없던 조직 설정을 현재 값으로 복원하지 않는다. 운영자의 조직 관리 위임은 실행 소속이 아니다. 소속과 배정이 충돌하면 임의로 우선순위를 정하지 않는다.

**Why:** 사용자가 기존 실행 불변성과 서버에서 검증된 소속을 명시적으로 요구했다.

**How to apply:** 모드 전환·재연결·평가 재생성은 실행에 저장된 이력만 읽고 새 실행만 현재 설정을 해석한다.

조직 평가 가중치는 실제 피드백 루브릭 항목에 연결한다. 시뮬레이션의 고정 다섯 차원과 이름이 다르면 임의로 대응시키지 않는다. 입력은 0~10 상대값이며 실제 점수에는 정규화 비중을 사용한다.

**Why:** 기존 조직 편집의 다섯 키와 실제 피드백 평가 키가 달라 저장만 성공하고 점수에는 반영되지 않을 수 있었다.

**How to apply:** 평가항목을 추가 생성하거나 유사 이름으로 추정 매핑하지 말고 일치하지 않는 키는 수정 전 적용을 차단한다. 키 이름이 우연히 같아도 피드백 가중치를 시뮬레이션 harness에 복사하지 않는다.

공개 목록 노출 여부를 조직 콘텐츠 실행 권한의 대체로 사용하지 않는다. 조직·카테고리 소유권 및 기존 스토어 사용권한으로 실행을 판정한다.

**Why:** 비공개 조직 전용 훈련도 해당 조직 학습자의 정상적인 사용 경로다. 공개 여부만 요구하면 조직 설정을 사용하는 핵심 경로를 막는다.

**How to apply:** 새 실행의 권한을 바꿀 때 비공개 조직 소유 콘텐츠의 소속 조직 허용과 다른 조직·무소속 차단을 함께 검증한다.
