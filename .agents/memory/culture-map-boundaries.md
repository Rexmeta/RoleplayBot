---
name: Culture Map independence
description: 사용자 지정 Culture Map 기능의 독립성 및 데이터 근거 경계
---

Culture Map은 기존 Persona와 독립된 모듈로 추가한다. 원본 페르소나에 문화 속성을 영구 반영하지 않고 기존 시나리오에 자동 적용하지 않는다. Actor별 옵션 기본값은 OFF이며 저장 설정은 시나리오 전용 스냅샷이다. 대규모 리팩터링은 하지 않는다.

**Why:** 사용자가 기존 서비스에 영향을 주지 않는 최소 침습적 독립 모듈 추가를 요구했다.

**How to apply:** 문화 관리·작성·실행 연결 작업에서 기존 Persona CRUD와 과거 실행을 보존한다. 공식 국가 수치라고 주장하려면 검증된 근거가 필요하며, 문화 차원을 개인의 고정 성격이나 평가 점수 직접 가감 근거로 쓰지 않는다.

사용자가 제공한 RoleplayX 자체 추정 자료는 공식 점수와 구분해 사용할 수 있다. 자체 추정·검토 전 상태와 원본 근거 수준을 유지하고, 인용된 연구기관이 그 수치를 직접 측정·검증했다고 주장하지 않는다.

**Why:** 2026-10-21 사용자가 공식 점수가 아니라는 고지와 검증 필요 상태를 포함한 자체 추정 데이터 및 등록 정책을 제공했다. 초기의 “공식 수치 임의 생성 금지”는 이 명시적으로 구분된 자료를 배제하라는 뜻이 아니다.

**How to apply:** 국가 프로필 등록·복제·Actor 선택에서 근거 수준을 숨기지 않는다. 첨부 데이터와 기존 앱의 척도 방향이 다르면 원본을 보존해 변환하며, 기존 저장 스냅샷의 의미가 달라지도록 전역 척도를 뒤집지 않는다.
