---
name: 시나리오 탐색 배치 원칙
description: 시나리오 목록 개편에서 사용자가 승인한 공간 배치와 그 이유
---

시나리오 목록에서는 큰 상단 개인화·필터 영역보다 좌측 탐색과 넓은 2열 목록을 우선한다. 개인화 정보는 작은 이어하기와 접힌 학습 요약으로 제공하고, 좁은 화면에서는 탐색 패널을 접는다.

**Why:** 사용자가 “상단 배치 개인화 영역, 필터 영역도 풀화면에서 상단에 고정되어 있어 불편한 상황”이라고 설명하고 좌측 메뉴 활용안을 승인했다.

**How to apply:** 시나리오 홈에 새 추천·통계·필터를 추가할 때 상단을 다시 크게 차지하지 않게 한다. 상세 정보는 목록의 행 높이를 늘리는 확장보다 목록 상태를 유지하는 오버레이로 제공한다.
