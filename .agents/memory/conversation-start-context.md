---
name: 대화 시작 안내와 선발화
description: PersonaX와 롤플레이의 첫 발화 차이와 시나리오 안내 바의 표시·시작 규칙
---

PersonaX는 페르소나가 먼저 말하고, 롤플레이는 사용자가 먼저 말한다. 두 모드 모두 캐릭터를 가리는 시나리오·장면 안내를 상단 접이식 바로 옮기고, 대화 진입 시 바를 연 상태로 시작한다. 최초로 바를 닫으면 음성 대화를 시작한다. 이후 다시 열고 닫는 것은 대화를 재시작하거나 첫 인사를 반복하지 않는다.

**Why:** 사용자가 PersonaX의 선발화를 명시했고, 시나리오 안내가 캐릭터를 가리지 않으면서 대화 시작 전에 인지되기를 요청했다.

**How to apply:** 화면 표시 상태와 최초 시작 승인을 분리한다. 재연결·이미 진행한 대화에서는 첫 인사를 반복하지 않는다. 라이브 아바타 유료 세션은 기존 명시적 마이크 시작 경계를 유지한다.

상단 숨김 바에서는 PersonaX와 롤플레이 모두 조직 오버라이드 표시를 제거한다. 실제 실행에 적용되는 조직 지침 자체를 제거하는 요청으로 해석하지 않는다.

**Why:** 사용자가 제거 대상으로 지정한 것은 숨김 바에 담긴 조직 오버라이드다.

**How to apply:** 대화 화면 정리와 실행 지침·평가 계약의 변경을 구분한다.
