---
name: Startup vs numbered migrations
description: 개발 시작 마이그레이션과 번호 SQL 마이그레이션의 적용 범위를 구분하는 규칙
---

런타임 연결 직후 또는 일반 요청에서 즉시 조회되는 테이블과 컬럼은 번호가 붙은 SQL 마이그레이션만 두지 말고 서버 시작 마이그레이션에서도 멱등적으로 보장한다. 커버리지 테스트는 두 경로를 합쳐서만 검사하지 말고, 시작 경로가 필수인 스키마를 별도로 검사한다.

**Why:** 번호 SQL 파일이 저장소에 있어도 개발 서버의 시작 경로가 그 파일을 실행하지 않을 수 있다. 두 경로를 합친 정적 검사는 실제 개발 DB의 누락을 숨기고 런타임 500 오류를 허용한다.

**How to apply:** 새 스키마를 추가할 때 실제 환경별 적용 주체를 확인한다. 연결 시작에 필요한 스키마는 `CREATE ... IF NOT EXISTS` 또는 동등한 시작 패치를 추가하고, 시작 경로 전용 회귀 검사를 둔다.
