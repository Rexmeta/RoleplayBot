---
name: Duplex 개선의 보존 범위
description: 실시간 Duplex·캐릭터 동기화 고도화에서 유지해야 할 기존 제품 기능
---

기존 RoleplayBot의 음성 대화, 감정 분석, 시나리오 시뮬레이션, 평가 기능을 유지하면서 실시간 Duplex 대화와 캐릭터 표정·감정 동기화를 고도화한다.

**Why:** 사용자가 고도화의 목적과 기존 기능 보존 범위를 명시했다.

**How to apply:** 새 음성/캐릭터 기술을 검토할 때 기존 엔진 교체를 전제로 삼지 말고 네 기능의 연속성과 회귀 검증을 개발 범위에 포함한다.

CharacterEmotion의 권위는 서버에 두고 클라이언트는 재생 상태에 따른 표정 표현 시점을 결정한다. UserAffect, CharacterEmotion, ScenarioState, ExpressionPresentation, AudioPlayback을 분리하며 기존 Simulation Engine 상태를 복제하거나 변경하지 않는다.

**Why:** 사용자가 상태 권위와 책임 분리를 추가 완료 기준으로 명시했다.

**How to apply:** 감정 revision·Persona generation과 출력 세대를 검사하고, 재생 관측을 물리적 청취나 외부 경로의 확인되지 않은 완료로 해석하지 않는다.

종료 시 유한 제한시간의 평가 확정 장벽으로 확정 전사·재생 관측을 정리한 뒤 Ledger 버전 또는 watermark와 불변 입력을 고정한다. 시간 초과·연결 종료 시 확인 불가를 보존하고 무기한 대기하지 않는다. 기능 플래그 의존성을 검증하고 세션 시작 시 동작 모드를 고정하며 기존/신규 경로를 유지해 단계별 롤백을 지원한다.

**Why:** 사용자가 평가 확정 시점, 세션 동작 고정, 롤백을 요구했으며 구현만으로 모델 품질이나 교육 효과 개선을 주장하지 않도록 명시했다.

**How to apply:** 작업 재시도·늦은 이벤트·재연결에서도 고정된 입력과 세션 모드를 유지하고, 기준선 대비 실측과 모델 품질·교육 효과 검증을 분리한다.

평가 종료 여부를 상위 대화 실행의 active 상태만으로 판정하지 않는다. 세션 재연결이나 늦은 Persona 변경이 이미 고정된 평가 참조를 제거해서는 안 된다.

**Why:** 피드백 대기 중에는 상위 실행이 active로 남아 있어도 Ledger와 평가 입력은 이미 종료·고정되어 있을 수 있다.

**How to apply:** 실행 상태를 다시 구성하는 모든 경로에서 종료된 증거 기록과 고정된 평가 참조를 독립된 권위로 취급한다.

끼어들기 후보 감지와 유효 발화 확정을 구분하고 잠정 중단만으로 학습자 턴·평가 근거를 확정하지 않는다. 지속 감정과 출력별 표현 감정을 구분하여 중단 출력의 표정·운율은 폐기하되 유효 사용자 발화·시나리오 사건이 일으킨 서버 감정을 무조건 롤백하지 않는다.

**Why:** 사용자가 중단 확정과 감정 인과관계를 추가 완료 기준으로 명시했다.

**How to apply:** 기존 VAD 기준선으로 즉시 중단/확정 후 중단의 지연·오탐을 비교하고 감정 갱신 원인을 추적한다. 동일 시나리오 UX 파일럿을 정의해 자연스러움·표정/음성 일관성·몰입감·체감 지연을 기술 KPI와 별도로 보고한다.

전역 평가 스냅샷 옵션은 아직 Duplex 설정을 고정하지 않은 레거시 실행의 음성 연결을 막지 않는다. 해당 실행은 평가 스냅샷만 제외한 유효 설정을 고정하고 기존 평가 방식을 유지한다. 이미 고정된 설정은 재연결에서 바꾸지 않으며 Ledger 자동 편입도 하지 않는다.

**Why:** Ledger 등록과 Duplex 전역 설정은 별도 활성화 경로이므로, 전역 평가 옵션만으로 레거시 연결을 거부하면 기존 음성 기능이 중단된다.

**How to apply:** 새 유효 설정을 결정할 때 기록 프로토콜을 확인한다. 이미 고정된 설정 자체가 프로토콜과 모순되면 무시하지 말고 오류로 처리하며, 종료된 평가·Ledger의 재연결 차단은 유지한다.
