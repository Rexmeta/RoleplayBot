# 라이브 아바타 120초 초과 운영 방안

## 현재 확인된 제한

- AvatarRouter의 공개 Full Pipeline 계약은 세션당 최대 120초다. 준비·대기 시간도 포함되므로 실제 대화 가능 시간은 더 짧다.
- RoleplayX 설정 응답의 `maxSeconds`와 시작 전 안내도 120초다.
- RoleplayX의 Tavus 런타임 검사에서 재사용하는 테스트 제한 스키마도 `sessionSeconds <= 120`만 허용한다. 라우터 값만 올리면 검사에 실패한다.
- 실제 종료 시각은 라우터 `expiresAt`과 워커가 결정한다. 브라우저 카운트다운만 수정해도 통화가 연장되지는 않는다.
- Tavus는 `properties.max_call_duration`을 지원하지만 계정 요금제의 최대 통화 시간을 초과하면 그 한도에 맞춰 제한한다. 현재 계정 한도는 별도 확인이 필요하다.

이번 개선에서 운영 한도, 요금제, 라우터 운영 코드와 배포는 변경하지 않았다.

## 권장안: 실제 대화 300초 + 준비 시간 별도

1. **라우터의 정식 시나리오 세션 정책 분리**
   - 관리자 진단용 120초 정책과 학습자 시나리오 정책을 분리한다.
   - 제안 계약으로 요청 시간, 허용 최대 시간, 실제 적용 시간, 준비 제한과 대화 시작 시각을 추가한다. 아직 지원하는 필드라고 가정해 요청하지 않는다.
   - 첫 목표는 실제 대화 300초다. 시나리오 시간과 계정 한도를 검증하고 서버가 최종 시간을 결정한다.
2. **준비 제한과 대화 제한 분리**
   - 예시: 준비 최대 60초 + 대화 최대 300초. 서버가 신뢰할 수 있는 제공자·참가자 준비 신호로 대화 시작을 확정한다.
   - 브라우저가 임의로 전송한 시각만으로 유료 세션을 연장하지 않는다.
   - 준비 제한을 넘으면 실패·정리 처리한다. 워커의 전체 수명 상한도 유지한다.
3. **라우터에서 Tavus 설정과 종료 시각 일치**
   - Tavus 생성 요청의 `max_call_duration`, 라우터 만료 시각, 워커 강제 종료, 비공개 방·접속 토큰 유효 기간을 일관되게 설정한다.
   - 위 예시에서는 전체 수명 상한 360초를 기준으로 정책을 설계하되, 제공자의 실제 시간 계산 기준과 요금제 한도를 검증한다.
   - 참가자 미입장·이탈 제한은 최대 통화 시간과 별개다. 재접속 허용 시간도 명시한다.
4. **예산·동시 실행 통제 유지**
   - 허용 세션 시간에 맞춰 사용자·프로젝트 일일 예산을 예약하고 사용량 정산·미사용분 반환 정책을 적용한다.
   - 대기 중 워커 점유와 정리 실패도 고려한다. 동일 과금 조건에서 120초를 300초로 늘리면 세션당 최대 통화 사용량은 2.5배다.
   - cleanup 차단, 불명확한 유료 생성 결과의 재시도 금지는 그대로 유지한다.
5. **RoleplayX 계약과 화면 갱신**
   - 진단용 제한 스키마를 그대로 늘리지 말고 시나리오 전용 런타임 스키마를 분리한다.
   - 설정의 고정 `maxSeconds: 120` 및 시작 안내를 라우터가 확정한 실제 허용 시간에 맞춘다.
   - 준비 시간과 실제 대화 시간을 구분해 표시하고, 남은 시간은 서버의 확정 종료 시각을 따른다.
6. **종료 후 기존 피드백 경로 유지**
   - 전체 대화를 하나의 세션·확정 대화록으로 저장하고 기존 평가 작업 큐로 보낸다.
   - 120초마다 유료 세션을 새로 만드는 우회 방식은 권장하지 않는다. 영상 단절, 컨텍스트 손실, 중복 과금 및 대화록 병합 위험이 있다.

## 반영 및 검증 순서

1. 실제 Tavus 계정의 허용 최대 통화 시간과 잔여 사용량 확인.
2. AvatarRouter에서 시나리오 전용 기간 계약·예산·워커·토큰 정책 구현 및 테스트.
3. RoleplayX의 스키마·설정·안내·타이머를 새 계약과 함께 반영.
4. 승인된 테스트 환경에서 실제 발화 120초 초과 및 300초 목표 통화, 조기 종료, 재접속, 탭 이탈, 예산 부족, 종료 후 확정 대화록·피드백을 검증.
5. 별도 승인 후 라우터와 앱 운영 배포. 외부 유료 테스트도 구현 승인과 별도로 승인받는다.
