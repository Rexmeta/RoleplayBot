# 조직별 시나리오 설정

## 권한·소속
- 관리자는 전체 조회 및 저장/삭제, 운영자는 기존 위임 조직 범위의 읽기/미리보기만 가능하다. 일반 사용자는 관리 API를 사용할 수 없다.
- 목록의 조직·시나리오 조건은 교집합이다. 전체·조직별·시나리오별·상세·미리보기에 동일한 조직 범위를 적용한다.
- 회사 위임은 기존 조직 위임 검사로 확장하며, 운영자의 관리 위임을 실행 소속으로 사용하지 않는다.
- 실행 소속은 서버 사용자 레코드로 확인한다. 소속 조직과 배정 조직이 다르거나 회사/카테고리 배정이 충돌하면 409로 차단한다. 무소속은 기본값을 사용한다.
- 다른 조직 전용 시나리오/카테고리에 대한 조직 설정을 선택·저장·실행할 수 없다. 비활성 조직/회사는 조회·삭제 가능하지만 저장과 새 실행 적용은 차단된다.

## 입력과 적용
- 용어는 AI 응답 지침이다. 원본 콘텐츠나 학습자 발화를 치환하지 않는다.
- 정책·금지 표현은 안전 규칙보다 우선하지 않는 응답 지침이다. 자동 감점이나 법적 준수 보장을 추가하지 않는다.
- 추가 상황 지침은 기존 문자열 배열이며, 자동 사건 트리거가 아니다.
- 문자열 공백을 정리하고 목록 중복을 제거한다. 빈 값·정규화 후 중복 용어 키·알 수 없는 필드·실제 평가에 없는 가중치 키를 거부한다.
- 용어 최대 50개, 목록별 최대 30개, 용어 키 최대 100자, 값/목록 항목 최대 1000자, 요청 최대 32KiB이다. 빈 새 설정은 저장하지 못하며 전체 제거는 명시적 DELETE다.
- **가중치 입력 단위는 0~10 상대값이며 백분율이 아니다.** 실제 피드백 루브릭의 활성 평가항목에 연결한다. 백분율 기본 가중치는 동일 비율의 0~10 상대값으로 표시한다(예: 60/40 → 6/4). 미지정 항목은 기본 상대값 유지. 최종 비중은 `상대값 / 상대값 합계 × 100`이다. 0은 유효하지만 최종 합계 0은 거부한다.
- 시뮬레이션의 다섯 고정 차원과 피드백 루브릭은 다른 계약이다. 이름이 다르면 임의로 매핑하거나 새 평가항목을 만들지 않는다. 기존 일치하지 않는 설정은 적용 불가로 표시하고 수정 전 새 실행을 차단한다.
- 키 이름이 같더라도 조직의 피드백 가중치는 시뮬레이션 harness 가중치를 변경하지 않는다. 가중치를 지정하지 않은 설정은 기존 피드백 루브릭 가중치 자체도 유지한다.

## 실행 불변성과 지원 경로
- 새 실행에서 기본/게시 시나리오 복사본에 조직 레이어를 결합한다. 기존 `scenario_runs.scenario_snapshot` / `evaluation_harness_snapshot` JSON 열을 사용하므로 SQL 스키마 변경이나 데이터 소급 마이그레이션은 없다.
- `_organizationOverride`에는 조직, 설정 ID/수정시각, 캡처 시각, 설정 항목, 최종 정규화 비중을 저장한다. 실제 루브릭도 `_evaluationCriteriaSnapshot`으로 고정한다.
- 게시/외부 반입 원본·Persona·Culture Map은 변경하지 않는다. 불완전한 외부 반입 게시 스냅샷은 현재 콘텐츠로 대체하지 않는다.
- 텍스트(일반/스트리밍, Gemini/OpenAI/OpenRouter), 실시간 음성, AvatarRouter의 기존 PCM 경로, Tavus Full Pipeline 컨텍스트, 공개 Agent API는 실행 스냅샷을 사용한다. 모델 전환·모드 전환·재연결·피드백 재생성 시 현재 조직 설정을 다시 조회하지 않는다.
- Tavus는 기존 AvatarRouter를 통해서만 연결한다. 기존 컨텍스트 크기/기능/동의 사전 검사를 유지하며 직접 Tavus 호출이나 추가 provider 호출을 만들지 않는다.
- 설정 조회 실패는 기본값으로 취급하지 않는다. 새 실행을 생성하기 전에 오류를 반환한다. 과거에 저장하지 않은 설정은 현재 값으로 소급 복원하지 않으며 UI는 과거 적용 기록을 확인할 수 없다고 표시한다.
- 대화의 조직 설정 요약과 피드백 루브릭의 조직 설정 요약은 저장된 이력에서만 표시한다. 설정 변경/삭제 및 소속 변경은 새 실행부터 적용된다.

## 검증 경계
권한·직접 요청 변조·입력·편집·실행 격리·실제 SDK 요청 payload·피드백 가중치는 모의 provider 기반 테스트로 검증한다. 이는 실제 모델의 완전한 지침 준수나 실제 유료 음성/영상 품질을 보장하지 않는다. 운영 DB 변경, 운영 배포, 실제 유료 호출은 별도 승인 대상이다.
