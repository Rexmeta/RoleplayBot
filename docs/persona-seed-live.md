# 페르소나 수정: 기존 기본 이미지로 라이브 설정

적용 위치는 **페르소나 관리 → 수정 → 라이브 아바타 → 맞춤 아바타**입니다.
원래 이미지·비디오, 로그인·관리 권한, 시나리오 정책·Gemini 기본 음성·평가를 바꾸지 않습니다.

## 관리자 흐름

1. 기존 기본 이미지를 먼저 저장합니다. 미저장 이미지로 전송을 요청하면 거절됩니다.
2. 권리·외부 전송·인물 유형을 명시적으로 확인하고 **시드 이미지 등록**을 누릅니다.
   서버는 권한 확인한 저장 이미지의 bytes만 기존 저장소에서 읽습니다.
   브라우저가 보낸 임의 URL을 다운로드하지 않습니다.
3. 이미지 등록과 유료 얼굴 생성은 별개입니다. 별도 비용 확인 후 **생성 요청**을 누릅니다.
   생성 이름은 실제 페르소나 ID입니다. Tavus 학습 보정은 AvatarRouter가 요청하고
   원본은 유지됩니다. 보정 성공·계정 잔액·생성 성공을 보장하지 않습니다.
4. 후보의 대기·처리·실패·조정 필요·재생 검증 필요를 확인합니다.
   실패는 Router의 안전한 `failure.messageKo`, 코드·단계·HTTP 상태를 표시합니다.
   같은 실패 이미지에 POST를 자동 반복하지 않습니다.
5. 처리 중·실패한 후보도 **초안으로 선택**해 일반 페르소나 수정과 함께 저장할 수 있습니다.
   재생이 검증되지 않으면 실제 대화에서는 거절됩니다.
6. 준비 완료 후보는 별도의 **재생 점검**에서 기존 명시적 비용·영상/음성 확인을 거칩니다.
   생성 완료가 재생 검증 완료를 뜻하지 않습니다.

## API와 저장 경계

기존 관리자 인증 아래:
- `GET /api/admin/personas/live-avatar/personas/:personaId/seed?source=...`: 읽기 전용 상태.
- `POST .../seed?source=...`: 권리·전송 확인 후 현재 저장 이미지 등록.
- `POST .../seed/create?source=...`: `{ "costConfirmed": true }`인 명시적 얼굴 생성.

`source`는 현재 편집 화면과 DB가 같은 이미지를 가리키는지 비교하는 용도입니다.
서버가 사용할 이미지 경로·페르소나 ID·tenant는 DB와 로그인 정보에서 결정합니다.
개인/조직 tenant + Router project + persona별 작업 기록을 분리합니다.
동시 쓰기는 PostgreSQL advisory lock으로 직렬화하고 외부 POST 전에
내구성 있는 단계를 저장합니다. 프로세스 재시작도 불확실 생성 차단을 지우지 않습니다.
등록 결과 자체가 불확실하면 추정 ID로 복구하지 않으며 운영자 확인이 필요합니다.
기존 POST는 자동 재시도하지 않습니다.

Router는 API 키의 `assets:read`, `assets:write`와 기능 검색의
`seed_image_live_options`, `custom_live_validation`, `client_playback_report`,
`customLiveProviders: ["tavus"]`를 제공해야 합니다.
`canProvision`은 로컬 조건이며 요금제·잔액·재생 성공의 증명이 아닙니다.

페르소나의 nullable JSONB `live_avatar_seed`에는 project/image UUID/version/
소스 fingerprint만 저장됩니다. 본문·이미지·URL·동의 증빙·비밀키는 저장하지 않습니다.
번호 migration `0025_persona_seed_live.sql` 및 기존 시작 migration 경로를 제공합니다.
**이 변경 작업에서 운영 DB migration을 실행하지 않았습니다.**

저장 시 현재 seed의 Router `live-options`를 다시 조회하여 후보와 버전을 확인합니다.
클라이언트의 검증 플래그·임의 provider ID는 신뢰하지 않습니다. 실제 대화 시작에서도
동일 이미지 버전·자산·검증된 참조·제공자 face ID를 재확인합니다.
삭제·만료·검증 무효화·프로젝트 변경은 활성화를 허용하지 않습니다.
시드가 바뀌면 이전 seed-backed 연결은 해제됩니다. 기본 아바타 참조는 별도 namespace입니다.
이전 이미지의 늦은 응답은 현재 화면에 적용하지 않습니다.

대화의 Tavus full은 기존 명시적 대체 엔진입니다. Gemini Live와 동시에 응답을 생성하지
않으며 이번 변경은 기존 대화 엔진 전환·시나리오 배정·평가를 수정하지 않습니다.

## 검증 범위

모의 API/저장소·컴포넌트 테스트만 사용합니다. 이미지 전송·실제 제공자 생성·유료 통화·
운영 데이터 변경·운영 배포를 실행하지 않습니다. PR이 병합·게시되기 전에는 운영 화면에
적용된 것이 아닙니다. 별도 승인 없는 실제 통화로 재생 성공을 주장하지 마세요.
